# pixellab-refs

Public reference images for PixelLab generation (style / character references passed by URL).
Base64 through the MCP transport truncates above ~12K chars; raw URLs from this repo have no such limit.

Layout: `<project>/<kind>/<file>` — raw URL pattern:
`https://raw.githubusercontent.com/Patrick0530/pixellab-refs/main/<project>/<kind>/<file>`

## magicwand/sheets
Character sheets for the six monsters (ChatGPT renders, 1448×1086, pixel grid period 4):
- `ref_sheet_1.png` key art (all six in a scene)
- `ref_sheet_2.png` roster: six columns, main sprite + variants + palette
- `ref_sheet_3.png` character sheet I: Ghost Fire, Eyeball, Slime
- `ref_sheet_4.png` character sheet II: Imp, Gargoyle, Demon Dragon
